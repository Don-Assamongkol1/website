## How posts work

Each post lives in `_posts/` with a filename like `YYYY-MM-DD-your-title.md`.
The front matter at the top (between the `---` lines) controls the title, date,
categories, and tags shown on the site.

## Writing in Markdown

You can use standard Markdown:

- **bold** and _italic_ text
- [links](https://example.com)
- `inline code` and fenced code blocks

```python
def hello():
    print("Hello, world!")
```

## Images

Place images in `assets/img/` and reference them:

```markdown
![Alt text](/assets/img/my-image.png)
```

That's it — commit and push, and the site rebuilds automatically.
